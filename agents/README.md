# Google ADK Agents

This directory contains AI agents built with the **Google Agent Development Kit (ADK)**.

## Structure

```
agents/
├── __init__.py          # Package init
├── main_agent.py        # Primary orchestrator agent
├── tools/               # Custom tools for agents
│   └── __init__.py
└── Dockerfile           # Container config
```

## Getting Started

```bash
pip install google-adk
adk web  # Launch the ADK dev UI
```
