# Sarvam AI Voice

This directory contains voice processing code powered by **Sarvam AI**.

## Structure

```
voice/
├── __init__.py          # Package init
├── voice_handler.py     # TTS / STT / Translation
└── Dockerfile           # Container config
```

## Sarvam AI Capabilities
- **Text-to-Speech (TTS)** — Indic language voice synthesis
- **Speech-to-Text (STT)** — Indic language transcription
- **Translation** — Multi-language translation
